

Welcome! This repository is a "sandbox" designed to help you master the **Open Source Contribution Workflow**. In the professional world, the quality of your Pull Request (PR) is just as important as the quality of your code. 

Your goal here is not to write software, but to learn how to communicate, document, and collaborate like a professional developer.

---

## 🎯 The Task
1.  **Fork** this repository to your own GitHub account.
2.  **Clone** your fork to your local machine.
3.  **Create a new branch** for your work (e.g., `git checkout -b feature/yourname-story`).
4.  **Create a new file** inside the `contributions/` directory named `yourname.md` (e.g., `sai.md`).
5.  **Write your content:** You can write about a story, a hobby, or a technical interest.
    *   **⚠️ IMPORTANT:** Do **not** include any personal contact information (email, phone number, physical address, etc.).
6.  **Commit and Push** your changes to your fork.
7.  **Submit a Pull Request (PR)** from your branch to the `main` branch of this repository.

---

## 📝 PR Requirements
To have your PR accepted, your PR description **must** include the following template.  Do Not Copy and paste this into the description box when you create your Pull Request write it by yourself and see whats happening in the preview: 

```markdown
### Summary
- What I added: [Briefly describe your topic]
- Why I chose this: [Briefly explain your interest]

### Checklist
- [ ] I have used proper Markdown formatting (headings, bold, lists).
- [ ] I have checked for spelling and grammar.
- [ ] I have followed the file naming convention (`contributions/yourname.md`).
- [ ] I have included the AI usage disclosure below.

### AI Usage Disclosure
- [ ] I have **not** used AI tools to generate this content.
- [ ] I have used AI tools to assist in writing/editing this content. 
*(If you checked the second box, please explain how: e.g., "Used for grammar check only".)*
